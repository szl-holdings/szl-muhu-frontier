## Research motivation

Sara Behnamian's work includes computational ancestry and machine
learning, while the Vidal-Gadea laboratory studies movement, calcium
physiology and neuromuscular biology. The WWOX literature includes
distinct molecular, organoid, preclinical and clinical-context
publications. Connecting these research references is useful only when
the graph does **not** treat author-name matches, search membership,
or citation-title words as validated biological relationships.

MUHU now provides a deterministic **source-identity provenance graph**
to prevent that conflation. It is **not** a biomedical knowledge graph
of gene-disease associations and does **not** infer scientific claims
from titles.

## Graph data model

Graph generated by standard-library-only Python with:
- **23** typed publication nodes (`PMID:<id>`)
- **23** DOI nodes from publisher DOI metadata
- **4** query-scope nodes
- **2** source-snapshot nodes
- **1** authoritative PubMed index node
- **53 nodes and 92 edges total**

Four *mechanical provenance* predicates are allowed, all source-bound
and noncausal:

`INDEXED_IN_SELECTED_SNAPSHOT`,
`SELECTED_FOR_BIBLIOGRAPHIC_QUERY`,
`REPORTED_DOI_IN_METADATA`, and
`METADATA_RETRIEVED_FROM_PUBMED`.

Each edge carries its originating snapshot SHA-256,
`PUBLIC_BIBLIOGRAPHIC_METADATA_ONLY` knowledge level, and explicit
false flags for biological or clinical claims. Graph construction
refuses mismatched snapshot bytes, duplicate PMIDs, dangling references,
cycles, unreviewed predicates, wrong node classes, mismatched DOI
counts, unauthorized query coverage and altered edge digests.

Graph SHA-256 at initial generation:
`8bd6c9fce288a64053db1b46f1fdf3f312e4dd4da0bfc9372b45b051f7f1dff8`.

These are original MUHU types. They were designed with attention to
the distinction between **retrieval provenance and scientific
evidence** in the Biolink Model, and entity/activity provenance
concepts from W3C PROV-O. **This is not a formal Biolink schema or
PROV-O conformance assertion.**

References:
[W3C PROV-O](https://www.w3.org/TR/prov-o/);
[Biolink source retrieval provenance](https://biolink.github.io/biolink-model/knowledge-source-retrieval/).

## Live read-only research routes

- `GET /graph` — source-bound SVG projection, clearly labeled 2D
  and explicitly not a working 3D digital twin.
- `GET /graph?topic=sara`, `?topic=vidal`, `?topic=wwox`,
  `?topic=worm_methods`, or `?topic=all` — four selected
  lanes without any automated relevance claim.
- `GET /api/v1/graph?topic=sara` — typed nodes, edges, source graph
  and view hashes, exact query membership.
- `GET /api/v1/graph/source?pmid=40627371` — exact evidence path
  and parent snapshot identifiers for the selected citation.
- `GET /api/v1/graph/search?q=AncestryGeni` — title-only bounded
  lexical retrieval, **not** evidence of model quality or accuracy.

Unknown PMIDs yield `UNAVAILABLE_NOT_IN_SELECTED_RESEARCH_SNAPSHOTS`;
this does **not** assert PubMed absence. Unknown topics, invalid
identifiers, duplicate query fields and URL-injection attempts return
HTTP 400. Mutations return 405. The existing Host allowlist remains.
This release adds no new NCBI request from the Hugging Face Space.

External PubMed and DOI links are clickable because their URL
hostnames are explicitly bound and validated in the pinned source
snapshots. The UI contains no JavaScript; it uses server-rendered
HTML and a source-derived, layered 2D SVG, not full interactive 3D.

## Scientific and operational ceiling

What it proves: source records and the allowed typed relationships
are **reproducible from the pinned public metadata** at observation
time, with stable edge and graph integrity checks.

What it does NOT prove: any statement in a paper is true, that a
therapy is safe or effective, that a WWOX variant is pathogenic,
that two experiments are mechanistically linked, that an author
has endorsed this work, or that a research model improves on a
baseline.

Before any genuine biology prediction model or Khipu/Flagship
adapter: obtain rights-cleared laboratory data, a source-to-claim
expert extraction protocol, fully independent blinded test cases,
a predeclared confidence/abstention benchmark, owner review and
the existing signed-job training admission process.

**FAILED/HOLD**. Flagship54's training controller and shutdown guard
were not changed by this bibliography graph.
