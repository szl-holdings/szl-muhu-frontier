# MUHU Research Governance and Reviewer Boundaries

This application is separate from the Sara Behnamian puzzle paper and
the Vidal-Gadea Lab methodological protocol. Public hyperlinks and
scientific-method concepts are not a copyright assignment, endorsement
or permission to ingest restricted laboratory records.

The draft Vidal-Gadea protocol v1.1 is NOT frozen. Neither raw laboratory
recordings nor unpublished student/strain data cross into this research
pilot. Scientific measurement, reproducible software gate behavior, and
biological validity are separately evaluated.

The original MUHU v1's research-gate classifier had 100% exact-input
cross-split overlap for validation/test. We retain that failure in
the training admission review (szl-gpu-bridge PR #228). MUHU v2 introduces
an explicit semantic-group split for its newly synthesized method
fixtures. This is a new narrow candidate; it is not proof v1 was
trained correctly, nor proof a model will generalize to biology.

Negative controls include missing source, zero denominator, missing
outside check, contradictory assertions, stale observations, unknown
fields, tampered labels, and attempted dataset split overlap.

Never claim genetics, medical advice, gene therapy, WWOX treatment,
real imaging improvements, or independent peer review from these
deterministic fixtures. Host the research preview only on CPU with no
third-party token injection, model execution, patient upload or
write/actuation API.
